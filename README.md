# FutureVideo

界面简洁、动效流畅的桌面视频播放器。全称 FutureVideo，简称 **fuvideo**。

内置播放内核，**安装后开箱即用**，不需要另外安装播放器或解码器。

## 下载安装

1. 打开 [Releases](https://github.com/YiZhiCRH380AL/fuvideo/releases) 页面
2. 下载最新版的 `fuvideo_x.x.x_x64-setup.exe`
3. 双击安装，装完从开始菜单启动

> **首次运行会提示「未知发布者」**，这是正常的——安装包还没有做代码签名。
> 点「更多信息」→「仍要运行」即可。

系统要求：Windows 10 / 11（64 位）。

## 怎么用

### 打开视频

**手边还没有视频？** 空状态里有 **看示例视频**：它会打开随应用带来的一小段片段（12 秒，
带一条字幕），点两下就知道这个播放器怎么用了。示例文件会复制到本机的应用数据目录，
你可以往那个文件夹里放自己的视频，也可以随时换成别处的目录。

点标题栏的 **选择目录**，挑一个放视频的文件夹。
目录里的视频会铺成一整面方格墙，每格显示这个视频的第一帧。

子目录铺在方格墙上面那条：点进去，点最前面的 **上一级** 回上一层。站在盘符根目录时那个
位置会变成 **此电脑**，里面列出所有能进的盘，不用再走一次系统对话框。

### 播放

**点一下方格**，它会放大成铺满整屏的画面，其他方格自动向下让位，视频随即开始播放。

- 点画面本身：播放 / 暂停
- 双击画面的**左半屏**：快退 10 秒；**右半屏**：快进 10 秒（会有涟漪提示）
- 鼠标悬停在进度条上：显示那个时间点的画面
- 看画面时鼠标不动约 2.6 秒，顶栏和底部控制条会一起隐去，鼠标动一下就回来

### 底部控制条

底部那条胶囊里是全部控制项，从左到右：

| 控件 | 说明 |
| --- | --- |
| ▶ / ❚❚ | 播放 / 暂停 |
| ⏮ / ⏭ | 上一集 / 下一集：按方格墙里的顺序换片，到头了会置灰 |
| 文件名 | 当前播放的视频 |
| 时间 | 已播时间 / 总时长 |
| 进度条 | 拖动跳转，松手生效 |
| 🔊 | 静音开关；鼠标移上去会展开音量滑块 |
| 1x | 倍速菜单，0.5x 到 2x |
| 音轨与字幕 | 换音轨、挑输出设备、切声道、调音频延迟；选字幕轨、挂外挂字幕、双语第二字幕、延迟与字号 |
| ⛶ | 全屏 |
| ⌄ | 收起画面，回到方格墙（会先暂停） |

音量和倍速会记住：退出时存下来，下次打开还是上次那样，不用每次开机重调。
窗口大小和位置也会记住；迷你模式下那个小尺寸不会被当成「常用尺寸」。

### 音轨与字幕

灵动岛上的 **音轨与字幕** 打开一个两页的面板：

- **音频**：换音轨（多语言片源）、加载外挂音轨、挑音频输出设备（列的是设备名字，比如「耳机 (USB)」，
  不是内部编号）、独占输出（开了之后别的程序就没声音）、声道（跟随文件 / 立体声 / 单声道 / 5.1 / 7.1）、
  音频延迟（画面和声音对不上时用它）。
- **字幕**：选字幕轨或者干脆关掉、**加载字幕文件…** 挂外挂字幕（srt、ass、ssa、vtt、sup 等）、
  开第二字幕做双语、字幕延迟、字号、位置。

输出设备、声道、字幕字号和位置是**全局偏好**，改一次以后一直用它；而这个视频选过的音轨和字幕
会跟着文件记住，下次打开还是它。换了别的视频想再改回来，面板里点一下就行。

ASS 字幕自带样式（字体、位置都写在字幕文件里），想让这里的字号真正生效，把「样式」从
**跟随字幕文件**切成 **用播放器样式**。

### 播放列表与收藏夹

鼠标移到任意一个方格上，它的右上角会浮出两颗小按钮：**≡** 加进播放列表，**☆** 加进收藏夹。
再点一次就是移出，按钮上会有对勾／实心星告诉你在不在里面。

标题栏右上角放着两个入口（在齿轮左边）：

- **≡ 播放列表**：这次想连着看的片子。↑ ↓ 调顺序、✕ 移出，点文件名直接播。
  **看完一个会自动播列表里的下一个**，到最后一个就停。
  每行底下那行小字是它所在的目录，点一下跳回去（和收藏夹一样）。
  面板顶上还有 **导出 / 导入 .m3u8**：导出的列表可以直接拖进 mpv、VLC 或别的播放器；
  导入是把文件里的路径**并进**现有列表（已有的跳过，不覆盖你排好的顺序）。
  列表攒多了想重来，面板顶上的 **清空** 按两下就清干净（第一下只是变成「确认清空？」）。
- **★ 收藏夹**：点文件名播放；点下面那行**小字（所在目录）**会跳回那个视频所在的目录，
  并把对应的方格高亮两下，方便一眼找到。

### 键盘快捷键

| 按键 | 作用 |
| --- | --- |
| `空格` 或 `K` | 播放 / 暂停 |
| `←` `→` | 快退 / 快进 5 秒 |
| `J` `L` | 快退 / 快进 10 秒 |
| `↑` `↓` | 音量增减 |
| `M` | 静音 |
| `F` | 全屏 |
| `T` | 迷你模式（缩成一小块，只看画面） |
| `[` `]` | 降低 / 提高播放速度 |
| `.` `,` | 前进 / 后退一帧 |

这些键都可以在「设置 → 快捷键」里改，按一下想改的那一行再按新键就行；改过的那条可以单条恢复默认，也可以一键全部恢复。

### 播放工具

右上角的 **⋮** 里放着几件偶尔才用一次的东西：

- **最近播放**：最近看过的片子按时间倒序排着，点一条直接接着看；
  鼠标移到那一行会露出 **✕**，可以把不想留的单条去掉
- **章节**：片子自带章节时列出来，点一下就跳过去
- **书签**：在当前位置打个标记，以后点一下就跳回来；只列当前这部片子的，✕ 可单条删掉
- **AB 循环**：在当前位置设 A 点 / B 点，两点之间反复放；「清除」把两端一起清掉
- **定时**：到点自动暂停，或者直接退出应用
- **窗口**：窗口置顶、迷你模式（都会记住，下次打开还是这样）
- **打开地址**：直接放网络地址，或任何 mpv 认的路径。`http/https`、`rtsp`、`rtmp`、`udp`
  都可以，边下边播；网速跟不上时进度条旁会出现缓冲提示。
  B 站 / YouTube 这类网页地址需要 **yt-dlp**（放在 PATH 或与安装包一起分发），
  没装时面板里会说明。
- **输入设备**：列出摄像头 / 采集卡与麦克风，选一个点「打开」就把它当成播放源。

另外，把文件或文件夹**拖进窗口**就能直接用：文件夹会铺成方格墙，视频文件直接开始播放。

## 支持的格式

播放内核基于 mpv / ffmpeg，格式覆盖接近本地播放器，不受浏览器限制：

- 常见容器：mp4、mkv、mov、avi、webm、flv、ts、m2ts、wmv、m4v、mpg、rmvb 等
- 常见编码：H.264、HEVC（H.265）、AV1、VP9 等
- 支持硬件解码，高码率视频也能流畅播放

如果某个视频打不开，欢迎反馈（见下），最好附上文件名、容器格式和编码信息。

## 常见问题

**需要另外安装 mpv 或者其他播放器吗？**
不需要。播放内核已经打包在安装包里。

**为什么 Windows 提示「未知发布者」？**
安装包没有代码签名。不影响使用，点「更多信息」→「仍要运行」即可。

**某个视频打不开，或者只有声音没有画面？**
请反馈给我，附上该文件的容器格式和编码（用别的播放器右键「属性」或「媒体信息」能看到）。
mpv 覆盖已经很广，遇到打不开的基本都是特殊封装，值得单独处理。

**第一次把鼠标放到进度条上，预览画面要等一两秒？**
那是正常的：预览用的画面是后台逐帧抽取的，刚开始还没铺满。看过几秒之后就随点随到了。

**快捷键没反应？**
先点一下画面让窗口获得焦点再试。如果焦点在输入框里，方向键会交给控件本身；
**在进度条上按方向键仍然是快退/快进 5 秒**（它自己的步长只有 0.1 秒，交给它等于没反应），
空格也仍然能暂停。

## 当前状态

**0.1.1-Alpha** — 早期预览版。功能已经在用，但界面和交互还会继续调整，欢迎提意见。

已知限制：

- 目前只支持 Windows
- 安装包未签名，首次运行会有 SmartScreen 提示
- 能放本地文件和直接给出的网络地址（`http://` 这类）；B 站、YouTube 那种网页视频要靠外部 `yt-dlp`，还没接
- 窗口透明度做不到：画面是播放内核的子窗口，分层窗口对它不生效，桌面透不过来
- 播放列表和收藏夹里如果文件被挪走或删掉了，点它只会提示找不到（还没有清理入口）
